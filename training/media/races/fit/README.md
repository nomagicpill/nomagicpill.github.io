# Race .fit files

Drop each race's Garmin/Wahoo `.fit` file here, named after the race's
HTML id (the `<h2 id="...">` anchor in ../../../races.html).

Examples:
  2026_freeforall.fit
  2026_litwhizzy.fit

The Links line in each race report points at media/races/fit/<id>.fit.
Add a matching link line when you add a new file.
