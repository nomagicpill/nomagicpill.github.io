Add-Link Bookmarklet

A one-click capture tool for the Links archive. On any page you're reading, optionally select a sentence to keep as a quote, then click the bookmarklet. It copies a ready-to-run command to your clipboard. Paste it in your terminal, type your note when prompted, and the entry is spliced into the current month of links.html for you.

Install

Drag this to your bookmarks bar: + Add to Links

Use

  1. While reading, optionally highlight a sentence to keep as a quote (rendered in "quotation marks").
  2. Click + Add to Links. The command lands on your clipboard.
  3. Paste it into your terminal and press Enter.
  4. At the Note: prompt, type your thoughts (or leave blank for a bare link), then Enter.

The title is auto-filled from the page tab. To override it, edit the --title '...' part before running. Run python3 knowledge/links.py -h for all options.

Note: some browsers only allow clipboard writes from a click (this is one), and a few block javascript: bookmarklets entirely. If nothing copies, the bookmarklet falls back to a popup you can copy from by hand.
