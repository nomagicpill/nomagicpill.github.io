Film bookmarklet

Adds a film to film.html from its Letterboxd page. It grabs the title, the year, and the 600×900 poster, stamps today's date, and leaves the rating and review blank to fill in later.

Install (once)

Drag this to your bookmarks bar:

Add film

If dragging doesn't work, right-click the link → Copy Link Address, then make a new bookmark by hand and paste that as the URL.

Use

  1. Open a film page on Letterboxd, e.g. letterboxd.com/film/sinners-2025/.
  2. Click Add film. A panel appears with a command already on your clipboard.
  3. Paste it into a terminal. That downloads the poster and inserts the entry.
  4. Later, open knowledge/film.html and fill in data-rating and the review.

The command it copies looks like:

python3 ~/Documents/nomagicpill.github.io/knowledge/add_film.py \
  --title "Sinners" --year 2025 --poster "https://a.ltrbxd.com/resized/….jpg"

It runs from any directory, refuses to add a film that is already listed (pass --force to override), and takes --date, --rating, and --dry-run if you want them. It is the film counterpart to knowledge/add_book.py.

Updating it

The bookmark itself is a five-line loader and never needs to change. All the logic lives in knowledge/film-bookmarklet.js, which the loader pulls from the live site each time you click it.

So to change what the bookmarklet does: edit that file, push, done. Every browser you installed it in picks the change up on the next click — no re-dragging, no reinstalling. The loader appends a timestamp to the URL so the 4-hour CDN cache never serves you a stale copy.

Two things to keep in mind. It needs the site to be reachable, so it won't work offline — you get an alert naming the URL that failed rather than a silent no-op. And it runs whatever is published, so an unpushed local edit has no effect; to try one before pushing, paste the edited file into the browser console on a Letterboxd tab.
